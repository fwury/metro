How to use Metro

Stations

  • Double-click or right-click empty grid to add a station
  • Right-click a station (or select it and press Enter) to edit its name, label side and marker
  • Drag stations or nudge them with the arrow keys — connections follow

Connections

  • Double-click a station to start a connection on the active line
  • Click grid points to add waypoints — the path runs along the grid between them and corners are rounded automatically
  • Double-click a station to finish, or empty grid to finish at a new station (Enter works too)
  • Hold ⌥/Alt to flip which way the next bend goes; Backspace removes the last waypoint; Esc cancels
  • Select a connection to drag its waypoint handles, drag a ＋ to add a bend, double-click a handle to remove it

Selecting

  • Click to select, Shift+click to add to the selection
  • Drag on empty space to select everything in a box
  • ⌘/Ctrl A selects all, Backspace deletes, Esc deselects

View

  • Scroll or Space+drag to pan
  • ⌘/Ctrl+scroll or pinch to zoom, F to fit the map

Shortcuts

  • 1–9 pick the active line
  • ⌘/Ctrl Z undo, ⇧⌘Z redo
  • ⌘/Ctrl S save file, ⌘/Ctrl O open, ⌘/Ctrl E export

Maps save automatically in this browser. Use Save file for a portable .metro.json copy.
